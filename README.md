# スーパーボリンジャー トレード支援エージェント (FX Trade Agent)

為替取引（FX）の代表的なテクニカル指標「スーパーボリンジャー」を活用し、ドル円（USD/JPY）の売買シグナル検知およびバックテスト結果を可視化するWebアプリケーションです。

## 🌟 特徴
- **マルチタイムフレーム統合表示**: 1画面に「サマリー」「1時間足」「4時間足」「日足」を `2 x 2` グリッドで美しく配置。
- **データギャップの完全排除**: 休場等の空白期間を詰め、Plotlyの等間隔カテゴリ軸と**不可視文字を活用した一意性確保ハック**により、描画の乱れを根絶。
- **日足実体のスマート補正**: 始値と終値が同値になりがちな提供元データのクセに対し、**「当日の終値を翌日の始値とする」** 補正を行い、実体を可視化。
- **完全自動モニタリング**: 手動更新の手間をなくし、**1時間ごとにブラウザ全体をバックグラウンドで自動リロードするJS**を搭載。

## 📈 売買ロジック定義 (マルチ・ロジック戦略)

本エージェントは買い（ロング）および売り（ショート）に対応し、最大1ポジションの単利運用（1万通貨固定、コストなし）を前提としています。ドテンは行わず、ノーポジション時にのみエントリーを判定します。

遅行スパンの陽転・陰転の判定は、ボリンジャーバンドの本来の定義である**「高安値基準 (HIGH_LOW)」**（現在の終値と21期間前のローソク足の高値・安値を比較するピンポイントブレイク）を採用しています。

### 【1時間足 (1h) ／ 4時間足 (4h)】: +2σエクスパンション厳選＆スピード決済モデル (HIGH_LOW)
- **買いエントリー (全3AND)**: 遅行スパン陽転 (`Close > 21日前High`) ＆ 終値 > **+2σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
- **買い決済**: 遅行スパン陰転 (`Close < 21日前Low`)
- **売りエントリー (全3AND)**: 遅行スパン陰転 (`Close < 21日前Low`) ＆ 終値 < **-2σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
- **売り決済**: 遅行スパン陽転 (`Close > 21日前High`)

### 【日足 (1d)】: 1σ厳選＆ダブルセーフティ決済モデル (HIGH_LOW)
- **買いエントリー (全3AND)**: 遅行スパン陽転 (`Close > 21日前High`) ＆ 終値 > **+1σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
- **買い決済**: 遅行スパン陰転 (`Close < 21日前Low`) または 終値 < **センターライン (21SMA)**
- **売りエントリー (全3AND)**: 遅行スパン陰転 (`Close < 21日前Low`) ＆ 終値 < **-1σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
- **売り決済**: 遅行スパン陽転 (`Close > 21日前High`) または 終値 > **センターライン (21SMA)**

## 🚀 セットアップと起動方法

### 1. 環境構築
Pythonの仮想環境 (`venv`) を作成し、依存関係をインストールします。
```bash
# 仮想環境の作成とアクティベート
python3 -m venv venv
source venv/bin/activate

# パッケージのインストール
pip install uv
uv pip install -r requirements.txt
```

### 2. アプリケーションの起動
以下のコマンドを実行すると、ローカルサーバーが立ち上がりダッシュボードが表示されます。
```bash
./venv/bin/streamlit run src/app.py
```

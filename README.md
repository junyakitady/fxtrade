# 📈 スーパーボリンジャー トレード支援エージェント (FX Trade Agent)

本システムは、為替取引（FX）や株式投資において、代表的なトレンドテクニカル指標である「スーパーボリンジャー」および「MACD」を活用し、ドル円（USD/JPY）および米国株（GOOG）のリアルタイム売買シグナル検知、評価損益トラッキング、および過去データに基づく厳密なバックテスト結果を可視化する**トレード意思決定支援ダッシュボード**です。

---

## 🖥️ 主なダッシュボードUI機能

本システムを起動すると、Streamlitによる直感的で洗練された以下のダッシュボード機能（UI）を利用できます。

### 1. 為替 総合サマリー (USD/JPY)
*   **リアルタイムステータスバッジ**:
    「1H スーパーボリンジャー」「1H MACDドテン」「日足 スーパーボリンジャー」の3つの戦略について、現在のポジション状態（🟢 買い保有中、🔴 売り保有中、⚪ ノーポジション）を一目で確認できます。
*   **評価損益のリアルタイム表示**:
    ポジション保有時は、エントリー建値と現在の評価損益（プラス時は緑、マイナス時は赤）がリアルタイムに表示されます。
*   **バックテスト成績表**:
    過去2〜5年間のデータを用いた厳密なバックテスト成績（総取引回数、勝率、累計損益）がグリッド内に一覧表示されます。
*   **適用ロジックの階層表示**:
    バッジの下部に、各戦略の「エントリー条件」と「エグジット条件」がインデント表記でわかりやすく明記されています。

### 2. インタラクティブ・マルチチャート
*   **1時間足 スーパーボリンジャー**:
    21期間のセンターライン、±1〜3σのバンド、および遅行スパンを描画し、過去の売買履歴マーカーを重畳表示した TradingView ライクなチャートです。
*   **1時間足 MACDドテン売買 (新機能)**:
    上段に「価格ローソク足 ＋ ドテン売買シグナルマーカー」、下段に「MACD線、シグナル線、およびヒストグラム（正負色分け）」を配置した、ズームやスクロールが上下連動する2段構成の高度な Plotly チャートです。
*   **日足 スーパーボリンジャー**:
    日足ベースでの長期トレンドをスーパーボリンジャー指標を用いて視覚化します。
*   **米国個別株トレンド分析 (GOOG)**:
    USD/JPY の下に独立したセクションとして配置され、ドル建て資産（GOOG）の日足トレンドサマリーとスーパーボリンジャーチャートを監視できます。

### 3. サイレント自動更新機能
*   ダッシュボード全体が 1時間ごとにバックグラウンドで最新データを自律ダウンロードし、画面をサイレントリフレッシュします。ブラウザの再読み込みをすることなく、放置監視が可能です。

## 📈 売買ロジック定義

ダッシュボード上で稼働しているシグナル判定ロジックの概要です。

### 【1時間足 (1h) スーパーボリンジャー】: +2σエクスパンション厳選＆スピード決済モデル (HIGH_LOW)
*   **買いエントリー (全3AND)**: 遅行スパン陽転 (`Close > 21日前High`) ＆ 終値 > **+2σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
*   **買い決済**: 終値 < **+1σ**（+1σ割れ）
*   **売りエントリー (全3AND)**: 遅行スパン陰転 (`Close < 21日前Low`) ＆ 終値 < **-2σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
*   **売り決済**: 終値 > **-1σ**（-1σ超え）

### 【1時間足 (1h) MACDドテン】: MACDのゴールデンクロス・デッドクロスによるドテン売買モデル
*   **買いエントリー (ドテン)**: MACDがシグナルを上抜け（ゴールデンクロス）。ショートポジションがあれば決済し、新規買い。
*   **売りエントリー (ドテン)**: MACDがシグナルを下抜け（デッドクロス）。ロングポジションがあれば決済し、新規売り。

### 【日足 (1d) スーパーボリンジャー】: 1σ厳選＆ダブルセーフティ決済モデル (HIGH_LOW)
*   **買いエントリー (全3AND)**: 遅行スパン陽転 (`Close > 21日前High`) ＆ 終値 > **+1σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
*   **買い決済**: 遅行スパン陰転 (`Close < 21日前Low`) または 終値 < **センターライン (21SMA)**
*   **売りエントリー (全3AND)**: 遅行スパン陰転 (`Close < 21日前Low`) ＆ 終値 < **-1σ** ＆ バンド拡大 (-2σ下向き かつ +2σ上向き)
*   **売り決済**: 遅行スパン陽転 (`Close > 21日前High`) または 終値 > **センターライン (21SMA)**

## 🚀 セットアップと起動方法

### 1. 環境構築
Pythonの仮想環境 (`venv`) を作成し、依存関係をインストールします。
```bash
# 仮想環境の作成とアクティベート
python3 -m venv venv
source venv/bin/activate

# パッケージのインストール
pip install uv
uv pip install -r requirements.txt
```

### 2. アプリケーションの起動
以下のコマンドを実行すると、ローカルサーバーが立ち上がりダッシュボードが表示されます。
```bash
./venv/bin/streamlit run src/app.py
```

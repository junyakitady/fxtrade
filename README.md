# スーパーボリンジャー トレード支援エージェント (FX Trade Agent)

為替取引（FX）の代表的なテクニカル指標「スーパーボリンジャー」を活用し、ドル円（USD/JPY）の売買シグナル検知およびバックテスト結果を可視化するWebアプリケーションです。

## 🌟 特徴
- **マルチタイムフレーム統合表示**: 1画面のダッシュボードに「サマリー」「1時間足」「4時間足」「日足」を `2 x 2` グリッドで配置。
- **レスポンシブ対応**: モバイルなどの縦長画面では自動的に各セクションが縦一列に並び、快適に閲覧可能。
- **欠損データのクレンジング**: 休場などにより取引データが存在しない期間を自動排除（ギャップ詰め）し、正確なテクニカル指標を算出。
- **インタラクティブチャート**: Plotlyを用いた美しく操作性の高いローソク足チャート。ボリンジャーバンド領域の透過表示や遅行スパン、売買シグナルマーカーを標準搭載。

## 📈 売買ロジック定義 (ロング・ショート対応)

本エージェントは買い（ロング）および売り（ショート）の両方向に対応し、最大1ポジションの単利運用（取引量1万通貨固定、コストなし）を前提としています。ドテンは行わず、ノーポジション時にのみ新規エントリーを判定します。

### 🟢 買いエントリー条件 (AND条件)
1. **遅行スパンの好転**: 当日の終値が、21期間前のローソク足の**高値**を上回っている。
2. **+1σ超え**: 当日の終値が、ボリンジャーバンドの「+1σ」ラインを上回っている。

### 🔴 買いポジション決済条件 (AND条件)
1. **遅行スパンの逆転**: 当日の終値が、21期間前のローソク足の**安値**を下回っている。
2. **+1σ割れ**: 当日の終値が、ボリンジャーバンドの「+1σ」ラインを下回っている。

### 🟣 売りエントリー条件 (AND条件)
1. **遅行スパンの逆転**: 当日の終値が、21期間前のローソク足の**安値**を下回っている。
2. **-1σ割れ**: 当日の終値が、ボリンジャーバンドの「-1σ」ラインを下回っている。

### 🔵 売りポジション決済条件 (AND条件)
1. **遅行スパンの好転**: 当日の終値が、21期間前のローソク足の**高値**を上回っている。
2. **-1σ超え**: 当日の終値が、ボリンジャーバンドの「-1σ」ラインを上回っている。

## 🚀 セットアップと起動方法

### 1. 環境構築
Pythonの仮想環境 (`venv`) を作成し、依存関係をインストールします。
```bash
# 仮想環境の作成とアクティベート
python3 -m venv venv
source venv/bin/activate

# パッケージのインストール
pip install uv
uv pip install -r requirements.txt
```

### 2. アプリケーションの起動
以下のコマンドを実行すると、ローカルサーバーが立ち上がりダッシュボードが表示されます。
```bash
./venv/bin/streamlit run src/app.py
```
